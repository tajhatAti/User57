# App Limiter

একটা Android App — অন্য App-গুলার জন্য দৈনিক ব্যবহারের সময়সীমা সেট করা যায়, সময় শেষ হলে সেই App বন্ধ করে হোম স্ক্রিনে ফিরিয়ে আনে। ডিজাইন: গাঢ় গ্রেডিয়েন্ট ব্যাকগ্রাউন্ডে iOS-style ফ্রস্টেড গ্লাস কার্ড।

## GitHub-এ আপলোড করে APK বানানোর ধাপ

1. GitHub-এ একটা নতুন repository বানান (public বা private, যেকোনোটাই চলবে)।
2. এই পুরো ফোল্ডারের সব ফাইল সেই repository-তে push করুন। উদাহরণ:
   ```
   git init
   git add .
   git commit -m "App Limiter first version"
   git branch -M main
   git remote add origin <your-repo-url>
   git push -u origin main
   ```
3. Push হওয়ার সাথে সাথে GitHub Actions অটো চালু হয়ে যাবে (repository-র **Actions** ট্যাবে দেখা যাবে, workflow-এর নাম "Build APK")।
4. Build শেষ হলে (২-৪ মিনিট লাগতে পারে) সেই workflow run-এর পেইজে নিচে **Artifacts** সেকশনে `app-debug-apk` নামে একটা zip পাবেন — সেটা ডাউনলোড করুন।
5. Zip খুললে `app-debug.apk` পাবেন — ফোনে কপি করে ইনস্টল করুন (Unknown apps থেকে ইনস্টলের অনুমতি চাইতে পারে, allow করে দিবেন)।

## App প্রথমবার চালু করার পর

App খোলার পর উপরে একটা ব্যানারে দুইটা বাটন দেখাবে — দুইটাই দিতে হবে, নাহলে limit কাজ করবে না:

- **Usage Access অনুমতি দিন** → এটা চাপলে সিস্টেম সেটিংসে নিয়ে যাবে, লিস্ট থেকে "App Limiter" খুঁজে Allow করে দিন।
- **Accessibility Service চালু করুন** → এটা চাপলেও সিস্টেম সেটিংসে নিয়ে যাবে, লিস্ট থেকে "App Limiter" খুঁজে toggle অন করুন।

দুইটা দেওয়ার পর App-এ ফিরে আসলে ব্যানারটা নিজে থেকেই চলে যাবে।

## ব্যবহার

- মূল স্ক্রিনে ফোনে ইনস্টল করা সব App-এর লিস্ট দেখাবে, সাথে আজকের ব্যবহারের সময়।
- যেকোনো App-এর পাশের **সময়সীমা সেট করুন** বাটনে চাপ দিয়ে মিনিট লিখে **সংরক্ষণ করুন**।
- সেই App যখন দৈনিক লিমিটের বেশি ব্যবহার হবে, App Limiter সাথে সাথে সেটা বন্ধ করে হোম স্ক্রিনে নিয়ে আসবে এবং "সময় শেষ!" স্ক্রিন দেখাবে।
- লিমিট বাদ দিতে চাইলে একই ডায়ালগে **লিমিট সরিয়ে দিন** চাপুন।
- প্রতিদিন রাত ১২টায় (মধ্যরাতে) ব্যবহারের হিসাব নিজে থেকেই রিসেট হয়ে যায়, কারণ এটা প্রতিদিনের usage stats থেকে হিসাব করে।

## টেকনিক্যাল নোট

- ভাষা: Kotlin, traditional Views (XML layout) + ViewBinding — Jetpack Compose ব্যবহার করা হয়নি, যাতে build সহজ ও নির্ভরযোগ্য থাকে।
- `minSdk 24`, `compileSdk`/`targetSdk 34`।
- Usage হিসাব করা হয় Android-এর `UsageStatsManager` দিয়ে, আর App বন্ধ করা হয় একটা `AccessibilityService` দিয়ে যেটা প্রতিটা App switch শোনে।
- এই App শুধু নিজের ফোনে সাইডলোড করার জন্য বানানো — Play Store-এ পাবলিশ করার জন্য না (তাই সিগনিং/রিলিজ কনফিগ নাই)।
